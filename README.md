# Exemplo de listas e filtros

Exemplo de utilização de listas, filtros, linhas e colunas com Flutter

## Tecnologias
- Flutter
- VsCode
- Android Studio

## Passos para testar
- 1 Clone este repositório
- 2 Abra com VsCode e em um terminal execute:
```bash
flutter pub get
flutter run
```
